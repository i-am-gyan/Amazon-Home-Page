# 🛒 Amazon Clone - HTML & CSS Project

A fully responsive clone of the Amazon home page built using only HTML and CSS. This project replicates the look and feel of the Amazon.com website with a clean layout, responsive design, and interactive UI components.

---

## 🔍 Project Features

- ✅ Responsive Navigation Bar with Logo, Search Bar, and Cart
- ✅ Location selector and sign-in section
- ✅ Hero Section with message and image
- ✅ Product Grid displaying multiple category cards
- ✅ Footer with useful links and branding
- ✅ Responsive design for desktop and tablet
